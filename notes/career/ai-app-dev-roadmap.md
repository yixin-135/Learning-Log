# 方向：AI 应用开发（Agent / 大模型应用）路线图

- 更新：开学初 / 目标：今年寒假拿到第一段 AI 应用开发实习

## 1. 为什么是「AI 应用开发」，不是「AI 产品经理」
- 产品经理：负责想清楚「做什么」（PRD / 原型 / 评审），不写核心代码
- AI 应用开发：负责「把它做出来、做好用」——调模型 API、搭 Agent、接 RAG、处理效果问题
- 你的优势：软件工程背景 + 已经能独立做端到端 Demo + 比纯开发多一层产品思维
- 一句话定位：**既能自己实现，又懂用户要什么**

## 2. 寒假目标岗位画像
- 岗位名：AI 应用开发实习生 / Agent 应用开发 / 大模型应用开发
- 招这类人的团队：字节扣子/豆包、百度千帆/文心、阿里百炼、腾讯元器、各家 AI Native 创业公司
- 面试重点：
  1. 一个能讲清楚、最好有真实用户的端到端项目
  2. LLM / Agent / RAG 原理能不能讲透
  3. Python 现场写代码（工具调用、检索、解析）
  4. 工程习惯：Git、README、模块化、错误处理、边界情况
  5. 加分项：Prompt 工程、评测方法、Demo/部署经验
